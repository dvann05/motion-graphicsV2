# Font custom (opsional)

Taruh file `.ttf` di folder ini kalau mau pakai font sendiri (misal font brand kamu).
Kalau folder ini kosong, script otomatis pakai font bawaan Ubuntu (DejaVu Sans Bold),
yang sudah diinstal lewat `fonts-dejavu-core` di workflow.

Font gratis yang enak dipakai buat motion graphics (lisensi aman dipakai komersial):
- Poppins / Montserrat / Inter — bisa diunduh dari Google Fonts (fonts.google.com)

Setelah menaruh font di sini, commit & push filenya supaya ikut terbawa saat workflow jalan.
